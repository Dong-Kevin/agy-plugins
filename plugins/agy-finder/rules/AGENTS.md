# AGY Finder 目录树定位链接约定

在回复中引用真实存在的本地文件或目录路径时，保持标准 `[文件名](file:///绝对路径)` 预览链接的同时，紧跟一个紧凑的目录树定位链接：

- 格式：`[📂](sidecar://agy-finder/tree/?path=<URL编码后的路径>)`（相对路径如 `src%2Findex.ts` 与绝对路径均支持；`/` 编码为 `%2F`，空格编码为 `%20`）。
- 仅用于真实存在的本地路径；不要为 `http(s)://` 网址、纯终端命令或假设示例路径添加 `[📂]` 链接。
- 当用户需要直接打开右侧目录树面板时，可输出 `[项目目录树](sidecar://agy-finder/tree/)`。
